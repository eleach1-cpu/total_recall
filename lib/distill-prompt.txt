Labels, exactly one per item:
- approved: the OWNER says yes, picks an option, gives an instruction, or authorizes work. Examples: "do it", "approved", "commit and push", "A, and call it X", "fix it", "go". An owner instruction is always approved, never completed. Only owner turns can be approved: CLAUDE saying "Agreed" or "Understood" approves nothing; if that same claude turn reports finished work it is completed, otherwise it is not an item.
- rejected: the OWNER turns down an option, approach, claim or wording, or tells CLAUDE to stop saying or suggesting something. For reason, copy the justification the owner gives in that same turn (a because-clause, or the fact cited against the idea, such as a measurement); null only when the turn gives none.
- standing: the OWNER states a rule for all future work: "never", "always", "from now on", "do not ... again", "every time", "only in". Only owner turns can be standing. When one owner turn both refuses something and sets a rule, output TWO items citing that same turn: one rejected, one standing.
- completed: CLAUDE reports work actually finished: shipped, pushed, fixed, reverted, renamed, done, tests passing. Never an owner instruction, never a line about work still in progress, never an answer to a question. A claude turn that agrees AND reports the work done ("Agreed. Renamed X to Y.") is completed.
- open: a task someone explicitly postpones or hands to a later session ("leave it for tomorrow", "still needs a test", "never got done, next time"). A question is not open. A progress report ("14 done so far", "running") is not open and not an item.
- proposed: CLAUDE offers an option or plan that the OWNER does not answer anywhere in this slice. If the owner answers it, output only the owner's answer (approved or rejected).
- superseded: a decision in this slice replaced by a later decision in this slice.

Never output: questions (anything asking for information, ending in ? or not), answers to questions that report no finished work, acknowledgements ("Noted", "Understood", "OK"), progress or status reports (counts, "so far", "running", "in progress"), greetings, shell or tool output, code, logs.
